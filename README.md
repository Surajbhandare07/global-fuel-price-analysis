# global-fuel-price-analysis
A data analysis project on global fuel prices (2015–present) using Python, exploring trends, correlations, and the impact of crude oil, demand, and global events.

# Global Fuel Price Analysis (2015–2026)

## 📌 Project Overview
This project analyzes global petrol, diesel, and natural gas prices to understand how factors like crude oil prices, demand, and global events influence fuel price fluctuations.

---

## 🎯 Objective
To analyze real-world fuel price data using Python and identify patterns, trends, and relationships that affect petrol prices globally.

---

## 📊 Dataset Information
- Source: Kaggle  
- Rows: 5860  
- Columns: 22  

The dataset includes fuel prices, economic indicators, and geopolitical factors such as:
- Petrol, Diesel, and Natural Gas Prices  
- Crude Oil Prices  
- Demand and Supply Index  
- Inflation Rate  
- Event Flags and Descriptions  

---

## 🧹 Data Cleaning
- Missing values were handled using mean and backfill methods  
- Text-based missing values were replaced with "No Event"  
- Duplicate rows were removed  
- Data was prepared for analysis and modeling  

---

## 📈 Visualizations
The project includes the following visualizations:
- Distribution of Petrol Prices  
- Top 10 Countries Petrol Price Comparison  
- Boxplot for Price Spread  
- Correlation Heatmap  
- Petrol vs Diesel vs Natural Gas Comparison  
- India Fuel Price Trends  
- Year-wise Trend Analysis  
- Event Impact Analysis  
- Crude Oil vs Petrol Relationship  
- Region-wise Price Comparison  

---

## 🤖 Machine Learning Model
A Linear Regression model was used to predict petrol prices based on various factors.

- Dataset split: 80% training, 20% testing  
- The model achieved high accuracy, showing strong relationships between variables  

---

## 🧠 Key Insights
- Petrol prices are strongly influenced by crude oil prices  
- Petrol and diesel follow similar trends  
- Fuel prices increase during global events  
- Prices vary across regions due to economic factors  

---

## 🌍 Recommendations
- Reduce fuel taxes during high crude oil prices  
- Invest in renewable energy sources  
- Improve public transport to reduce fuel demand
